# Платформа НОК Кыргызской Республики · мобильное приложение

Внутренняя платформа для 14 сотрудников аппарата. Весь интерфейс за авторизацией.

## Стек

Expo SDK 57, React Native, TypeScript, Expo Router, NativeWind (Tailwind 3), TanStack Query,
react-hook-form, zod, i18next, date-fns, lucide-react-native, FlashList, @gorhom/bottom-sheet,
Reanimated, expo-secure-store, expo-auth-session, expo-notifications, Biome. Менеджер пакетов — pnpm.

- Маршруты — `src/app/routes/` (опция `root` плагина expo-router), провайдеры — `src/app/providers/`
- Тема — CSS-переменные NativeWind через `vars()` в `ThemeProvider`, тема навигатора тоже из токенов
- Шрифт: у каждого `<Text>` задавай `font-regular` / `font-medium` / `font-semibold` / `font-bold`
  (`font-sans` нет — на iOS семейство без веса не подхватывается)
- Нативные пакеты ставь через `npx expo install`, не через `pnpm add`
- `ios/` и `android/` генерируются (`expo prebuild`) и не в git — нативные правки только
  через config-плагины (`plugins/`)
- Правила по Expo — в `AGENTS.md`

Макеты: Figma, ссылки в `../docs/figma.md`.

## Чего не делать

- Не добавляй UI-библиотеки со своими стилями: MUI, Ant, Chakra, React Native Paper. Дизайн свой.
- Не предлагай SSR и Next.js. Публичных страниц нет.
- Не добавляй Redux, Zustand, MobX. Серверное состояние — TanStack Query,
  локальное — useState и useReducer.
- Не настраивай монорепо, workspaces, Turborepo, Nx. Приложения web и mobile независимы.

## Удаление

Почти ничего нельзя удалять:

- Запись журнала действий — никогда и никем
- Сотрудник — деактивируется, не удаляется
- Задача — закрывается или архивируется
- Документ — аннулируется, номер остаётся занятым

По сроку удаляются только резюме (6 месяцев), транскрипты и уведомления (12 месяцев).

## Согласованность чисел

Если на экране есть счётчик, он должен совпадать с содержимым.
«Готово 8» при трёх видимых карточках — ошибка. Пиши «3 из 8».
Это частая ошибка, проверяй каждый раз.

## Даты

Самая частая ошибка — даты. Проверяй день недели и рабочие дни по производственному календарю КР:
дедлайн не должен выпадать на выходной, «просрочено N дней» не может стоять у даты в будущем.

## Проверки приёмки

Шестнадцать проверок в `../docs/priyomka.md`, три блокирующие.
Прежде чем менять права, сессии или журнал — перечитай соответствующую проверку.

## Стиль кода

- Отступ 2 пробела, одинарные кавычки, точка с запятой, строка до 100 символов (Biome)
- Компоненты в `src/features/`, переиспользуемое в `src/shared/ui/`
- Типы API генерируются из OpenAPI командой `pnpm api:sync`, руками не пишутся
- Токены из `src/shared/config/tokens.ts`, цвета в коде не хардкодятся.
  Файл продублирован в web и mobile — правь оба
- Тексты интерфейса только через i18next, ключи во всех трёх файлах `src/locales/` (ru, ky, en)

## Перед коммитом

`pnpm lint` и `pnpm typecheck` должны проходить.
